# TechHub Shopping Cart System

## Project Overview
The TechHub Shopping Cart System is a web-based application developed as part of the Professional Development (PFD200) module.

The system allows users to browse technology products, add products to a shopping cart, update quantities, remove items, and calculate purchase totals.

## Project Objectives
- Develop software development skills
- Improve web development knowledge
- Gain experience using GitHub
- Build a professional digital portfolio

## Technologies Used
- HTML
- CSS
- JavaScript
- Java
- GitHub

## Features
- Product Catalogue
- Shopping Cart
- Quantity Management
- VAT Calculation
- Order Summary
